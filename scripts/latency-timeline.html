How to read one keystroke row

Time runs left to right. One keystroke has an upper track and a lower track.

1. Gray: scheduling delay

Scheduled time → generator dispatch. How late the generator sent the key.

2. Yellow: input delivery delay

Dispatch → browser keydown. How long the sent key took to reach the browser's input handler.

3. Dark blue: local text latency

Keydown → expected text detected in the typing user's document.

4. User color: observer text latency

Keydown → expected text detected in the observer's document. The color changes with the user.

Both blue intervals start at keydown. The lower bar overlaps the local update; do not add those durations. Dispatch is a point in time, not a blue bar.
